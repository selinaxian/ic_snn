# 时序学习机制验证：已完成，未通过完整序列选择性检验

日期：2026-11-11。保留00snn原编码、网络参数和3个模型种子，没有金融收益标签，没有因结果不理想调参。完成9个网络训练、选型锁、独立背景检验、权重更新拆解、连接干预，以及缺成分补充检查。

**结论：STDP确实改变并强化了部分连接，但本轮锁定的三个候选神经元主要对最后一个C信号响应，未证明它们学会了“A先、1分钟后B、再2分钟后C”的完整顺序。** 与随机/乱序STDP对照比较，没有得到真实顺序训练的额外顺序选择性证据。

这不等于所有64个神经元的联合活动完全没有顺序信息，也不是STDP的一般不可能性证明。它是当前参数、当前编码、当前合成分布、当前候选选择与发放计数响应的机制检验结果。

## 1. 实际运行范围

- 训练：40个独立生成的120分钟人工半日，各10次目标序列，共400次，重复3遍。不是40个真实交易日。
- 选型：16个新背景半日，160个序列上下文。
- 检验：32个新背景半日，320个上下文。每个上下文派生不同顺序/间隔/缺成分对照，不把这些派生样本视为独立。
- 3个初始化种子104/211/307；每种子随机权重、真实顺序STDP、乱序STDP三组。三组输入编码与初始化配对；随机组也按原规则适配阈值。
- A/B/C为输入特征0/1/2的正通道；其他9特征产生背景。事件位置在12分钟格内随机偏移，背景与幅度在选型/检验时重新生成。
- 每半日连续推进电位与发放迹；半日边界清瞬时状态，保留训练权重和阈值。
- 检验每个对照从同一段真实连续回放前史的快照分叉，背景、起始电位、迹、权重、阈值完全相同。没有把起始状态不同当成顺序区别。
- 候选神经元只按选型数据确定，锁文件在评价该模型检验集前写入。三个STDP候选为11、4、53号（编号从0开始）。

主协议和输入/代码哈希在运行前保存。原协议含缺C；only_A/B/C、missing_A/B、no_events六组是在看到首个种子选型权重后补充的解释性检验，未重选神经元，也未改训练。补充时点与边界见 `component_check_protocol.md`。

## 2. 最直观的结果：最后一个C，而不是完整ABC

观察窗口固定为序列局部第3至6分钟，即包含最后事件C以及随后3分钟。以下是三个STDP候选在320个新背景上下文中的响应率，先按样本计算后对3种子平均。“响应”表示该窗口内至少放电一次，不是分类准确率。

| 检验输入 | STDP候选响应率 |
|---|---:|
| A@0 → B@1 → C@3 | **55.00%** |
| B@0 → A@1 → C@3，最后仍是C | **55.10%** |
| A@0 → B@2 → C@3，改变间隔 | 53.13% |
| A/B/C同时在第3分钟 | 43.23% |
| C@0 → B@1 → A@3，完全反序 | 0.73% |
| 只有第3分钟的C | **56.88%** |
| 删除A，保留B/C | 59.38% |
| 删除B，保留A/C | 55.63% |
| 删除C，保留A/B | 0.63% |
| 只有A | 0.31% |
| 只有B | 0.94% |
| 没有A/B/C，只保留背景 | 0.52% |

如果只比较ABC与CBA，会看见巨大差异，并容易误判成功。但CBA把C放在早期，ABC把C放在最后，测量窗口又在后段。这种差异可以来自“对最近C敏感”。保持末尾C相同、只交换A/B后，区别基本消失；只有C也能引起相近响应。这些控制共同支持上述解释。

缺成分后响应有时更强，可以来自竞争、前面的发放重置和输入作用等非线性变化；本轮没有逐机制分离这些原因，不能仅凭这张表声称精确知道是哪一种动力学造成。

来源：`response_profiles.csv`、`test_responses.csv`、`component_responses.csv`。

## 3. STDP有没有比随机和乱序学得更好

主要指标固定为ABC与BAC（末尾C相同）的配对顺序胜率：同一背景下目标响应更多记1，相同记0.5，更少记0。这是配对比较，不是普通ROC AUC，也不是一个已训练分类器的准确率。

| 模型 | ABC相对BAC的配对顺序胜率 |
|---|---:|
| 随机权重 | 50.99% |
| 真实顺序STDP | **49.95%** |
| 乱序STDP | 52.76% |

真实顺序STDP减随机：−1.04个百分点，95%探索性区间[−2.40,+0.21]个百分点。

真实顺序STDP减乱序STDP：−2.81个百分点，区间[−4.11,−1.51]个百分点。

不能把乱序组这一小优势解释成它掌握了市场时序；这只是当前选择和响应指标下的对照结果。核心是原顺序训练没有显示目标顺序优势。

完全反序的比较中，STDP相对随机有明显改善，但相对乱序STDP仍无优势；这进一步表明只看ABC/CBA不够。改变间隔、同步输入对照也没有给出STDP相对两条基线的优势。

区间将同一上下文的3种子先平均，再按32个检验半日分块重采样2000次。未进行多重比较校正，初始化只有3个，不能将960个模型响应当作960个独立背景。

来源：`response_summary.csv`、`paired_intervals.csv`。

## 4. 编码有没有把问题本身毁掉

保留原Poisson式编码，不补发脉冲。检验期320个ABC中，245个（76.56%）三个信号都成功产生至少一个脉冲，其余至少遗漏一个。

但只看三个信号都编码成功的245个上下文，真实顺序STDP的ABC/BAC配对胜率仍为 **49.80%**，并没有恢复顺序选择性。这个子集是解释性统计，不重新选神经元，也不代替主结果。

输入正负控制：

- 直接按已知生成模板读取正确通道/分钟位置，ABC/BAC配对胜率99.84%。这是知道模板的输入诊断，不是训练出的神经模型，也不能归功于STDP。
- 只读全窗口输入总脉冲数，胜率严格50%，因为前五种对照逐通道计数严格相同。

因此，编码确有遗漏，但完整编码输入仍能区分这些序列。现有证据不支持把神经候选的失败全部归咎于Poisson噪声。

来源：`encoding_coverage.csv`、`all_events_encoded_subset.csv`、`input_controls.csv`。

## 5. 哪些连接真的强化了

三个STDP候选中，最终A/B/C三条连接里最大的均是C→候选神经元：

| 初始化种子 | 候选神经元 | C连接初始权重 | 最终权重 |
|---|---:|---:|---:|
| 104 | 11 | 0.2394 | **0.5265** |
| 211 | 4 | 0.3784 | **0.4838** |
| 307 | 53 | 0.2847 | **0.5512** |

不是所有A/B连接都增强，例如种子104的A连接0.2798→0.2481；种子211的A连接0.4158→0.1674。因而不能描述为“ABC每个参与信号都被一致强化”。

种子104、神经元11的C连接，完整训练累计：

```text
初始权重                            0.239365
原始LTP累计增强                    +1.446308
原始LTD累计减弱                    -0.418827
裁剪与权重归一化累计作用           -0.740306
最终权重                            0.526540
```

累计增强量大于1不表示某一步权重超过上限；它是三遍训练所有小更新的和。每步仍执行原有裁剪和归一化。

已逐步按原代码记录pre/post迹与实际post，不改训练公式。9个模型所有连接的“LTP−LTD＋裁剪归一化”重构最终减初始权重，最大误差约 **5.31×10⁻¹⁴**；额外测试确认加入审计后权重与未审计原推进逐元素一致。

这证明局部配对确实改变了连接，不能单凭权重账本证明该连接学习了完整序列。

来源：`selected_signal_connections.csv`、`connection_updates.csv`、各模型`*_plasticity_audit.npz`。

## 6. 屏蔽关键连接后发生什么

候选关键连接只在选型阶段固定：候选单元的A/B/C中最终最大权重。对照连接从其他通道选最终权重最近者；实际两者输入活动量和权重未严格匹配，具体数值已保存，因此不把它称为完全公平的因果效应估计。

下表为同样320个上下文、三个STDP候选的平均发放数：

| 固定网络干预 | ABC平均发放数 | BAC平均发放数 |
|---|---:|---:|
| 原样 | 0.5500 | 0.5510 |
| 删除候选C连接 | **0.0010** | **0.0010** |
| 删除匹配无关连接 | 0.4021 | 0.4104 |
| C连接恢复初始化权重 | 0.0708 | 0.0646 |

C连接确实是这些候选响应的重要来源，且强化后的权重提高了响应。但删除C同时消除了ABC与BAC响应，二者原本也没有明显差异。因此这里证明的是**C响应依赖该连接**，不能表述为“屏蔽了ABC顺序识别连接”。

干预仅作用于局部序列起点之后，前史状态相同；不归一化其他连接，不训练，不修改最终保存的模型。竞争网络中的其他神经元可能因干预发生响应变化，这是受控网络实验，不是市场因果结论。

| 检验环节 | 结果 |

不能说“STDP完全没有学习”；它学习改变了输入敏感性。也不能说“老师设想已实现”：尚未建立稳定的完整事件序列选择性。

## 8. 限制与后续边界

本轮每个网络只锁定一个候选神经元，按目标相对四种对照平均响应差选出；该准则可能倾向最后事件敏感的单元。没有对64维联合轨迹训练序列解码器，因此结论限制在这些锁定单元和固定响应统计，不能推断整个网络不存在任何顺序信息。

此外，测试背景来自训练过的同一种生成分布，事件时刻只在固定12分钟格内随机变化，事件幅度范围有限。我们没有通过改变编码、时间常数、竞争规则或新增延迟支路来补救，避免把失败修到成功后只报告最后一次。

下一步若继续，应先决定是检查64维完整时序响应中是否仍可读出顺序，还是引入明确的延迟组合结构。本轮不自动实施两条新路线，也不把这些候选送去金融收益筛选。原v8的延迟结构虽有合成成功记录，但不能直接充当当前连续模型的证明。
