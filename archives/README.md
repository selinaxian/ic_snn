# 大型研究文件归档

代码、配置、研究报告及小型结果表在各项目目录中直接保存。大型 CSV 和 NumPy 模型、发放记录以无损 tar.xz 分卷保存于本目录，每卷不超过 90 MiB。

文件内容、原始路径、字节数和 SHA256 记录在 manifest.json。原始全市场分钟 ZIP、01 至 04 参考资料目录、虚拟环境和依赖缓存不包含在仓库中。IC 项目实际输入数据保留在这些归档及项目目录中。

克隆仓库后，在仓库根目录执行以下命令恢复原目录结构（仅需 Python 标准库）：

```sh
python archives/restore.py
```

脚本检查所有分卷及原始文件的校验值，不覆盖已经修改的本地文件。仅验证归档，不解压写入：

```sh
python archives/restore.py --verify-only
```

这些是 2026-11-13 的固定研究快照。原本较大的文件路径已加入 .gitignore，修改原文件不会自动更新归档；如需发布新快照，应保留旧归档另建版本并更新清单，避免误以为 Git 已保存新结果。tools/package_repository.py 记录本次打包方法，不应在已有分卷的情况下直接覆盖运行。
