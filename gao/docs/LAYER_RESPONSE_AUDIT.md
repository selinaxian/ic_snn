# Gao 基线逐层响应诊断

## 范围与结论

本轮只分析 gao 的 Poisson 版本（20 仿真步/分钟），不是 00snn 的确定性编码版本。使用已有 180 个测试日、3 个种子、随机池及 STDP 池，共 1080 个冻结模型；每个种子/池有 35,640 个分钟。没有训练、修改阈值、选择策略或修改原基线。

结论：隐藏层存在输入敏感的响应差异，输出脉冲数量保留了一部分差异，最后的 any-spike 二值化几乎抹平了盘中区分。但差异对随机编码也敏感，隐藏层活动广泛，当前不能认定隐藏层已经提取了有金融价值的特征。既不是“整个网络完全没有反应”，也不是“只换读出就一定解决”。

## 冻结干预

1. actual：原始行情和原编码种子，逐分钟精确复现原结果。
2. constant：因子固定为各自训练日的均值，包括 session_progress；保留与 actual 相同的逐小步随机数，因此编码概率改变才会改变输入脉冲。该对照改变发放率及计数，不是等计数的时点置换。
3. new_encoding_seed：行情和模型都不变，只将测试编码种子改为原种子加 1000003。每个原种子只做一个扰动；不是全面编码稳定性估计，也没有重新训练。

每个半日从同样初态开始，半日内部连续推进。两组对照都保留输出层一个仿真步传输延迟。所有实际输出计数、H1/H2 分支计数与原始保存结果一致；每次回放检查权重完全未变。

## 一、差异在什么地方被压缩

“改变的分钟比例”是同一分钟两次回放数值不相同的比例，不是分类准确率，更不是信息量或收益预测能力。高维向量更容易不相同，不能据此直接比较不同维数的表征质量。

| STDP 池比较，真实输入对恒定输入 | 三个种子结果 |
|---|---:|
| 隐藏层完整 20×128 发放图改变 | 接近 100% |
| 128 维逐神经元分钟计数向量改变 | 99.54%–99.58% |
| 输出神经元 20 步发放图改变 | 84.82%–86.24% |
| 输出神经元分钟发放数量改变 | 43.21%–44.20% |
| 最终二值事件改变 | 0%–0.0337% |

差异并未全部在隐藏层到输出层的连接中消失：输出计数仍频繁不同。将所有正计数压成 1，确实丢掉了盘中大量可见差异。另一方面，从 128 个计数到一个计数本来就会压缩，不能把所有被压掉的部分都称为有用金融信息。

随机池也有相似的压缩现象：输出计数约 43% 的分钟改变，二值事件完全不变。尚不能据此认为 STDP 带来了优于随机池的表征。

## 二、隐藏层是否也过于容易发放

真实输入下，随机池平均每分钟约 385 个隐藏脉冲，STDP 池约 642–643 个，即每个隐藏神经元平均约 3 次与 5 次。

三个种子合并，随机池有 98.7738% 的分钟所有 128 个隐藏神经元都至少发一次；STDP 池为 99.9916%。所以用“哪些隐藏神经元这一分钟发过”同样几乎没有辨别力，需要看数量、时点或群体结构，而不能宣称隐藏层天然有稀疏选择性。

隐藏输入连接没有达到 0.99 的权重；每个隐藏神经元入权重总和从初始 2.4 增长至平均 6.958。隐藏层并非权重上限饱和，但广泛活跃。此前输出层总入权重从 1.2 增至中位数 127.9 是另一个层次的问题。

STDP 输出真实输入下平均每分钟约 5.58–5.63 次，78.31% 的分钟至少发 6 次。当前不应期为 2 步、20 步一分钟，单神经元理论上最多约 7 次/分钟，输出靠近速率上限。部分模型全天沉默也拉低了整体均值；不能用“触发率九成”理解为每天均匀筛选掉一成分钟。

## 三、是否是稳定的行情差异

仅换测试编码随机种子时，STDP 池：

- 隐藏层计数向量约 99.87%–99.90% 的分钟改变。
- 输出计数约 47.90%–48.71% 的分钟改变。
- 单隐藏神经元计数平均绝对变化约 0.716–0.720 次；真实/恒定对照为 0.645–0.649 次。
- 输出计数平均绝对变化约 0.540–0.549 次；真实/恒定对照为 0.475–0.487 次。

这说明可见差异不一定全部来自金融变化。不能据两种干预的差异大小计算“噪声占比”：重抽全部随机数对输入的扰动更大，而恒定对照复用了同一份随机数，两者不是同等扰动强度。本轮支持编码敏感性，不支持“随机噪声贡献超过金融信息”的定量判断。

## 四、金融含义的有限检查

为避免把“不同”当成“有用”，保存了逐分钟隐藏总计数、活跃隐藏神经元数、输出计数和事件。固定检查同一连续交易时段内下一分钟 close-to-close 收益及其绝对值，每种子/池有 35,280 个共同标签点，不跨午休/隔夜。不拟合读出、不挑因子、不调预测期限。

仅作历史描述：去除日期均值和钟点均值后再作秩相关，STDP 隐藏总计数与下一分钟收益相关约 −0.0020 至 +0.0034，与绝对收益约 +0.0006 至 +0.0063；输出计数与收益约 −0.0031 至 −0.0021，与绝对收益约 +0.0068 至 +0.0097。

这些相关很小；没有检验出经济可用性、成本后价值或对原始因子的增量。本轮去均值只作混杂诊断，使用全诊断样本统计量，不能作为实盘因果信号变换。所有日期已经用于研究。没有做多重检验或把这些值当成独立样本显著性结果。完整隐藏时空图可能还有结构，简单总计数检查不能否定它，也不能证明它。

## 下一步应如何收敛

先不替换模型、编码或直接提高阈值。已明确的实现瓶颈是广泛隐藏活动、输出连接上限饱和及 any-spike 事件压缩。若继续修改，应单独校正输出学习尺度/约束，在训练期检查它是否避免普遍饱和，同时保留原隐藏响应作为对照；冻结后再检查是否对行情差异有可复现的响应。不能按测试利润选参数，也不能把信号变少作为成功标准。

输出计数可以作为最简单的诊断读出留存，但目前不能称为有效交易因子。进一步验证读出稳定性时，应用多次编码重抽检验同一金融分钟的分数一致性，再谈金融增量。这里只完成定位，没有擅自更改基线或开始新一轮训练。
